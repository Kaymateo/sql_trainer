SQL 训练场 · 使用说明
========================================

一、它是什么
  本机 SQL 刷题平台：随机出题 + 自动判题 + 错题本 + 八股自测。
  42 道复杂 SQL 题（窗口函数/连续区间/留存漏斗/行列转换/多表关联/日期时间/数仓建模）
  + 136 张理论面试卡片（Linux/SQL/Hive/Spark/Kafka/Flink/数仓/调优/手写代码/项目HR）。

  每道题出题时会随机生成一套全新的业务数据（约 2 万行 / 9 张表），
  参考解在同一套数据上算出标准答案，你的 SQL 和它逐行对拍判分。
  → 每次做题数据都不同，背答案没有用。

二、怎么打开（VM 上的服务已在运行）
  宿主机浏览器打开：  http://172.16.105.2:3000

  如果 VM 重启过、打不开，在 VM 里执行：
      cd ~/sql_trainer
      ./run.sh 3000

  首次运行会自动创建虚拟环境并安装依赖（duckdb + pyarrow），之后秒起。

三、怎么用
  1. 左侧题库按分类列出 42 道题，✓=已通过 ●=做过没过 ○=没做；
  2. 中间是题目要求和数据字典（点开看每张表的字段和真实样例数据）；
  3. 下方编辑器写 SQL：
        Ctrl + Enter  提交判题
        Ctrl + Space  表名/字段名补全
  4. 不会写就点「提示」（分 3 级：思路 → 关键语法 → 易错点）；
  5. 提交后：通过/未通过 + 具体差异（缺哪些行、哪个值不对），
     标签页可看「我的结果 / 参考结果 / 参考解 / 考点讲解」；
  6. 每题下面有笔记框，记自己的踩坑点，自动保存；
  7. 做错的题自动进「错题本」，可以一键「用新数据重做」；
  8. 「理论卡片」页：先自己想答案，再点「显示答案」对照，可标记掌握度；
  9. 「统计」页：通过数、通过率、练习天数、各分类掌握度进度条。

四、目录结构
  app.py            服务端（HTTP API + 进度库 + 数据实例缓存）
  engine.py         数据生成引擎 + 判题引擎 + 安全护栏
  bank/             题库（spec.py 是题目模板定义，ex_*.py 是 42 道题）
  static/           前端（原生 JS + CodeMirror，已本地化，不需要联网）
  tools/            理论卡片提取脚本
  tests/            三层验收测试（引擎 / 接口 / 前端 DOM）
  data/             进度库 progress.db + 理论卡片 flashcards.json
  README.md         完整文档（出题原理、判题规则、怎么加新题、验收记录）
  run.sh            一键启动

五、想加题 / 想改数据规模
  见 README.md 的「怎么加新题」一节：在 bank/ 下加一个 Exercise(...) 即可，
  重启服务自动生效。改完跑一下自检：
      cd ~/sql_trainer && PYTHONPATH=. .venv/bin/python tests/test_bank.py 8

六、安全说明
  平台只读：拒绝 DDL/DML/ATTACH/COPY/装扩展/读本地文件，且只允许单条查询语句，
  20 秒超时自动中断。可以放心在上面乱试 SQL。
